Litematic → WorldEdit

Turn Litematica .litematic builds into WorldEdit .schem files. Everything runs in your browser — nothing is uploaded.

    Using it on the server

    1. Put the .schem file in the server's plugins/WorldEdit/schematics/ folder.
    2. In game, stand where the build's corner should go and run //schem load name.
    3. Run //paste -a (the -a skips air so it won't carve out terrain). Use //undo if it lands wrong.

    Multi-region schematics are merged into one. Chests, signs, banners and other block data come along; mobs/item frames are included as entities (paste with //paste -ae to place them).
