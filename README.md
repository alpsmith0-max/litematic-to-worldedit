# Litematic → WorldEdit Converter

Convert Litematica `.litematic` builds into WorldEdit / FastAsyncWorldEdit `.schem` files, right in your browser. Nothing is uploaded.

Use it: https://alpsmith0-max.github.io/litematic-to-worldedit/

Put the `.schem` in `plugins/WorldEdit/schematics/`, then `//schem load <name>` and `//paste -a`.
